# 速卖通欧美站 · 全托管上架全套方案提示词 v1

> 来源：需求方现有工作流提示词。系统中作为「内容生成」的默认模板，变量 `{{product}}` 由 1688 商品数据注入。

现有一款国内货源商品，对标亚马逊、eBay、速卖通欧美站点同类爆款，遵循速卖通平台规则完成全套上架优化。

参考维度：国内货源商品标题与主图、同品类核心卖点及产品特性、亚马逊 eBay 速卖通欧美站热销同款标题逻辑、爆款主图营销卖点。

【标题强制生成规则，必须严格遵守】
标题生成公式：核心关键词 + 属性词 + 核心关键词 + 长尾词 + 流量词；流量权重从左至右依次降低。
- 核心关键词必须放置在标题前 30 字符区间；
- 核心关键词重复次数最多不超过 3 次；
- 实词首字母大写，冠词、介词、连词小写，标题禁止使用任何标点符号；
- 英文标题精准控制在 115 个英文字母，不是字符，附带中英双语对照，高点击率，贴合海外买家搜索习惯。

【产品简介硬性要求】
产出 3 种差异化风格文案，全部中英双语对照，输出内容可直接复制用于商品详情页：
① 带 emoji 活泼吸睛款
② 简约专业商务款
③ 场景化氛围感种草款

【完整输出交付清单，必须全部输出】
1. 中英对照标题（严格遵守上方标题全部规则）
2. 3 套差异化双语产品简介
3. 五点 Bullet Points 详情卖点（中英双语）
4. 6 张主副图全套营销规划（对标欧美爆款逻辑，800*800px，含首图、细节图、2 张场景图、功能演示图、参数信息图，参数图标注 cm/inch 双单位）
5. 后台搜索词库（标题埋词 + 后台关键词）
6. 平台合规 & 欧美市场运营提示（侵权风险、目标受众、速卖通短描述截取建议）
7. 【产品自定义属性】中英双语对照，方便复制

执行要求：参考欧美同类热销商品数据，输出适配速卖通欧美市场的完整可直接上架全套方案。
