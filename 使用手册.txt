                 速卖通上品助手  v1.0  使用手册

【先看这个：两个端口别搞混】
------------------------------------------------------------------------
  8000  = 界面端口。你用浏览器访问 http://127.0.0.1:8000
  9222  = 浏览器调试端口。程序内部用来操作妙手/1688，你不需要亲自打开

  两个端口不同，也不冲突。
  如果 9222 没起来，界面顶部会出现黄色提示条，选品会失败（不会给你编数据）。


一、这套系统能帮你做什么
------------------------------------------------------------------------
从「一个想法」到「妙手里待认领的商品」，中间这些活它会自动干：

  1) 选品：说一句"厨房类目挑 3 个"，它去速卖通看真实热销数据，
     再回 1688 找货源，按毛利打分给你候选
  2) 出内容：标题（严格按 115 字母规则）、3 套双语简介、5 点卖点、
     6 张主副图规划、后台搜索词、合规提示、中英属性
  3) 定价：成本 ≥10 元按 (原价+运费+5)×2 自动算；
     成本 <10 元会主动问你定多少
  4) 送进妙手：一键采集 + 把标题/描述/颜色名改成英文

剩下的三步平台限制只能人工：认领、选类目属性、点发布。


二、前置条件（缺一不可）
------------------------------------------------------------------------
[必须]
  1. Windows 10 / 11
  2. Python 3.11 或以上（安装时勾选 "Add Python to PATH"）
  3. 妙手 ERP 账号（能正常登录 erp.91miaoshou.com）
  4. 妙手开放平台 App ID + App Secret（妙手后台 → 开放平台）
  5. DeepSeek API Key（platform.deepseek.com 申请）

[浏览器：不用你操心]
  本工具自带一套浏览器内核（装依赖时已下载），也会自动找你电脑里的 Chrome/Edge。
  你只要点界面顶部的「自动启动浏览器」，或双击 2-启动服务.bat 即可。
  起来后弹出的那个浏览器窗口，第一次需要登录 妙手ERP + 1688，之后长期有效。

[可选]
  6. 火山方舟 Key —— 只有要"AI 生图"才需要，不配也不影响上架
  7. 妙手图片翻译额度 —— 要把 1688 图里的中文翻成英文才需要

[重要：浏览器必须是"调试模式"的 Chrome]
  本工具要操作妙手/1688 页面，必须连一个带调试端口(9222)的 Chrome。
  用普通方式打开的 Chrome 不带调试端口，程序会一直提示"浏览器未连接"。
  正确做法：双击 2-启动服务.bat，它会自动帮你启动这个 Chrome。

  这个 Chrome 用的是**独立配置目录**（%LOCALAPPDATA%\SumaiAgent\chrome-profile）：
   · 好处：不需要关掉你平时用的 Chrome，互不影响
   · 代价：第一次要在这个窗口里重新登录一次 妙手 ERP、1688
   · 登录一次后长期有效


三、第一次安装（只做一次，约 5 分钟）
------------------------------------------------------------------------
  1. 双击  1-安装依赖.bat
     → 自动建虚拟环境、装依赖、装浏览器内核（等它跑完）

  2. 双击  4-首次配置（生成设置文件）.bat
     → 会弹出记事本，填三处后保存：
         "llm": { "api_key": "sk-你的DeepSeekKey" }
         "miaoshou_api": { "app_id": "ak_xxx", "app_secret": "xxx" }

  3. 双击  2-启动服务.bat
     → 它会依次：启动调试 Chrome(9222) → 启动服务(8000) → 用 Chrome 打开界面
     → 在那个 Chrome 窗口里登录：妙手 ERP、1688
     → 出现"9222 已就绪"才算成功


四、每天怎么用（核心流程）
------------------------------------------------------------------------
  第 0 步  双击 2-启动服务.bat（约 15 秒），确认窗口显示 9222 已就绪
  第 1 步  对话工作台输入："厨房类目帮我挑 3 个新品"
           → 草稿出现在「审核台」
  第 2 步  审核台勾选 → 点「① 采集＋英文（一键）」
           → 采集进妙手公共采集箱；标题按 115 字母规则重写、描述/颜色名翻英文
           ⚠ 只处理你勾选的；不勾才会处理全部
  第 3 步  点「② 认领到全托管」（或去妙手手工勾选认领）
  第 4 步  妙手里打开商品编辑页，补 5~8 个必填类目属性 → 保存
  第 5 步  点「④ 提报已确认商品」或在妙手点发布


五、已知限制（别踩坑）
------------------------------------------------------------------------
  × 认领、类目属性、发布：妙手没开放速卖通全托管接口，这三步只能人工点。
  × 图片翻译：按张扣额度，额度用完会失败；无文字的图会自动跳过省钱。
  × 库存：妙手接口上限 99999，超过会被截断。
  × 1688 搜索：频繁搜索会弹滑块，弹了需要在 Chrome 里手动滑一下。
  × 生图：需单独配置火山方舟 Key，不配就是"未启用"。


六、常见问题
------------------------------------------------------------------------
  Q: 页面顶部出现红色「模型异常」
     → 说明大模型调用失败（Key 错、余额用完、网络问题）。
       不影响已有草稿，但当前这轮没法继续理解你的话。
       点右侧「去设置」检查 DeepSeek Key 与模型名，然后重说一次。

  Q: 页面顶部出现黄色「模型未配置」
     → 还没填 DeepSeek Key。到「设置」填上即可，选品/对话都依赖它。

  Q: 界面顶部出现黄色「浏览器未连接」
     → 最快办法：点黄条上的「自动启动浏览器」，等 3~10 秒会自动消失。
     → 服务启动时也会自动尝试拉起浏览器，一般不需要你手动处理。
     → 起来后记得在那个浏览器窗口里登录 妙手ERP / 1688 / 速卖通。
     → 如果一直失败：检查是不是杀毒软件拦了浏览器的调试端口。

  Q: 8000 和 9222 到底谁是谁
     → 8000 是你在浏览器里访问的界面；9222 是程序操作网页用的调试端口。
       两个不同，不冲突。界面黄条只跟 9222 有关。

  Q: 界面打不开 / 白屏
     → 那个最小化的黑色窗口（sumai-server）是不是被关了？
       重跑 2-启动服务.bat。日志在 data\server.log

  Q: 点界面链接，跑到 Edge 里去了
     → 3-打开界面.bat 已改成强制用 Chrome。
       若仍走 Edge，说明系统里没装 Chrome，或 Chrome 装在非标准路径。

  Q: 选品一直失败
     → 十有八九是 9222 没连上，或那个 Chrome 没登录 1688/妙手/速卖通。

  Q: 点"属性转英文"提示没找到属性
     → 当前没打开商品编辑页。它会自动跳到全托管采集箱，
       点某条商品的「编辑」，再点一次按钮。

  Q: 服务老是掉
     → 改用「启动-守护（可选）.bat」，崩溃自动拉起。

  Q: 数据在哪 / 怎么备份
     → 全部在 data\ 目录（drafts.json 草稿、settings.json 配置）。
       复制整个 data 文件夹即可备份。


七、目录说明
------------------------------------------------------------------------
  1-安装依赖.bat           一次性安装
  2-启动服务.bat           每天启动（调试Chrome + 服务 + 打开界面）
  3-打开界面.bat           只用 Chrome 打开界面
  4-首次配置.bat           生成并编辑配置
  启动-守护（可选）.bat    守护模式
  chrome_debug_user.bat    以调试模式启动 Chrome
  server\                  后端程序
  web\                     界面
  data\                    配置与数据（可备份）
